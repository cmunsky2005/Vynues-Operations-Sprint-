# Baseline Data Intake Tracker

This tracker exists to collect the real operational data needed to populate the T7 Baseline Metrics and KPI Dashboard. Every "To Be Established" cell in those two documents should be filled from this tracker once the source data is pulled 

**No values in this document are populated yet.** This is intentionally a blank intake form, not a filled baseline. Baseline numbers must come from actual records; a placeholder guess here would defeat the purpose of a baseline.

## Recommended Baseline Window

Per the Baseline Collection Process (T7, Steps 1–4), pick a defined window — e.g., the most recently completed calendar month or the last 5–10 completed events — rather than an arbitrary "since we started" range, so the baseline reflects current operating conditions rather than early, unrepresentative activity.

## Next Step

Once this tracker has at least one populated row per KPI category, the T7 Baseline Metrics and KPI Dashboard documents should be updated from "To Be Established" to real values, and T1's KPI closure, T4's measured bottleneck impact, and T8's ongoing monitoring can all move from framework to operating.
