## What Is This?

This is the **T3 supply chain map** for Vynues. It documents how an event moves through the full operation — from the moment a client requests an event, all the way to post-event resolution.

It follows the **SCOR model**, which breaks the supply chain into five steps:

```
PLAN → SOURCE → MAKE → DELIVER → RETURN
```

## The Five SCOR Steps

---

### 1. 🟦 PLAN
**Figure out what you need before you need it.**

- Client submits an event request
- Ops checks venue and vendor availability
- Budget and timeline are scoped
- A vendor shortlist is drafted

---

### 2. 🟩 SOURCE
**Find it, vet it, and contract it.**

- Venues and vendors are identified and vetted
- Quotes are collected and compared
- Contracts and SLAs are signed
- Deposits or purchase orders are issued

---

### 3. 🟨 MAKE
**Prepare and stage the event.**

- Run-of-show document is created
- Vendors are briefed with logistics
- Site walkthrough and final confirmations are completed

---

### 4. 🟧 DELIVER
**The event actually happens.**

- Vendors execute their contracted scope
- On-site coordinator manages the day
- Issues are resolved in real time
- Incident log and client satisfaction are tracked

---

### 5. 🟥 RETURN
**Handle what comes after.**

- Client complaints or disputes are resolved
- Vendor invoices are reviewed and approved
- Vendor performance scores are updated
- Root cause of any issues is logged for next time

## Glossary

| Term | Definition |
|---|---|
| **SCOR** | Supply Chain Operations Reference — the five-step framework used in this document |
| **Run-of-show** | A minute-by-minute timeline of everything happening at the event |
| **SLA** | Service Level Agreement — a contractual performance promise from a vendor |
| **Vendor vetting** | Checking a vendor's credentials, insurance, and reliability before approving them |
| **Incident log** | A real-time record of problems on event day |
| **Vendor scorecard** | A running performance record for each vendor |
